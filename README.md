# Teacher's Day Website — Premium Version

## Files

- `index.html` — separate premium Home page
- `teachers.html` — separate Explore Teachers page
- `style.css` — all visual styling

## Teacher information

Open `teachers.html`.

At the top of its `<script>` section there is a `teachers` array containing
Teacher 1 through Teacher 130.

For each teacher replace:

- `name`
- `subject`
- `photo`
- `bio`
- `opinions`

Example:

{
  name: "Mrs. Anitha",
  subject: "Mathematics",
  photo: "images/teacher-1.jpg",
  bio: "Your teacher bio...",
  opinions: [
    "Anonymous student appreciation...",
    "Another appreciation..."
  ]
}

Create an `images` folder beside the HTML files and put the photos there.

## Home page

`index.html` contains:

- premium Teacher's Day hero
- large block-style Happy Teacher's Day title
- abstract background art
- Explore Our Teachers button
- About the Celebration section
- celebration image placeholder

## Publishing

The website is static HTML/CSS/JavaScript and is suitable for GitHub Pages.
Upload `index.html`, `teachers.html`, and `style.css` to a GitHub repository.
If using photos, upload the `images` folder too.

## B9 / Title Block

The homepage uses a heavy slab-serif title treatment inspired by the B9 “TITLE BLOCK” reference supplied for the design. It loads Roboto Slab from Google Fonts, with Rockwell/Georgia fallbacks.
